# ملعب رمضان ٢٠٢٧ — النسخة ٢

تطبيق ويب تقدّمي (PWA) بيتثبت على أندرويد وآيفون وبيشتغل **بدون إنترنت**. مفيش خطوة بناء: ملفات ثابتة ترفعها على أي استضافة HTTPS (Netlify / GitHub Pages / Cloudflare Pages / Firebase Hosting).

## التشغيل محلياً
```
python3 -m http.server 8080      # ثم افتح http://localhost:8080
```
(لازم سيرفر، مش فتح الملف مباشرة، عشان ES modules والـ Service Worker.)

## النشر
ارفع محتويات المجلد كما هي على استضافة HTTPS. كل نشر جديد: غيّر `VERSION` في `sw.js` عشان الأجهزة تاخد التحديث.
- أندرويد: Chrome ← «تثبيت التطبيق».
- آيفون: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

## المميزات
- ٣٠ يوم بخريطة وتفتح حسب التاريخ (`ramadanStart` في `js/config.js` أو من لوحة الإدارة).
- كويز يومي ٥ أسئلة بصعوبة متدرجة، مؤقت، نقاط سرعة، مضاعف سلسلة الإجابات، مساعدات (٥٠:٥٠ / +١٠ ثواني / تخطّي).
- وضع الضغط للأيام ٢٦–٣٠ (الوقت يزيد مع الصح وينقص مع الغلط).
- عجلة حظ يومية، سؤال الليل (بعد ٧ مساءً)، مستويات، ١٣ شارة، سلسلة أيام.
- تدريب حر بدون حدود بالأقسام والصعوبة.
- منع الغش: الخروج من الشاشة = السؤال خطأ، وإغلاق التطبيق وسط الجولة لا يسمح بإعادتها.
- لوحة إدارة: إضافة/إخفاء/حذف أسئلة، استيراد JSON (يدعم صيغة `quizzes_pool` القديمة)، تاريخ رمضان، إعلان.
- نسخة احتياطية/استعادة لبيانات اللاعب.

## الأسئلة
البنك المدمج ~١١٦ سؤال، والـ ٣٠ يوم محتاجين ١٥٠ عشان مفيش تكرار. استورد أسئلتك القديمة من لوحة الإدارة ← إضافة ← استيراد.
مراجعة الأسئلة المدمجة دينياً قبل الإطلاق مسؤوليتك.

## تفعيل الترتيب العالمي والفرق (اختياري، Firebase)
1. أنشئ مشروع Firebase **جديد** (مفاتيح القديم كانت مكشوفة في الكود، وكود الأدمن كان مكتوب فيه).
2. فعّل Authentication ← Anonymous، وFirestore.
3. الصق إعدادات الويب في `firebase-config.js`.
4. ارفع `firestore.rules`.
5. للأدمن: افتح التطبيق مرة، خد الـ UID من Authentication، وأنشئ مستند بنفس الـ UID في collection اسمه `admins`.
6. الأسئلة المنشورة من لوحة الإدارة بتتحمّل عند اللاعبين وتتخزن محلياً فتشتغل أوفلاين.

⚠️ طبقة Firebase (`js/backend-firebase.js`) مكتوبة لكن **لم تُختبر على مشروع حقيقي**. وبدون Cloud Functions لا يمكن منع التلاعب بالنقاط تماماً؛ القواعد بتمنع النقصان وتحدّ الزيادة لكل تحديث فقط.
